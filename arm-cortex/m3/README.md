# Arm Cortex M3 Devices

## STM32VLDISCOVERY Board

* STM32F100RBT6B Microcontroller
* Built-in SWD via USB
* User Button: Pin PA0 (GPIO A pin 0) Active High
* LEDS: Active High
    * LD1 USB Communication PA9 (GPIOA pin 9P) Red
    * LD2 3.3V Power On Red
    * LD3 on PC8 (GPIO C pin 8) Blue
    * LD4 on PC9 (GPIO C pin 9) Green
