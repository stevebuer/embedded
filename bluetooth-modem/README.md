# nRF51 Development

BLE 400 with nRF51822 modules

## Tools

* Segger Embedded Studio on Linux (Free Hobby / student License request form)
* nRF5 12.3.0 SDK (last version to fully support nRF51822)
* S130 soft core
* ST-Link V2 SWD (need to get J-Link)

## Notes

* Examples are not in SES project format, so need to be imported from Keil MDK (Arm 5 compiler) projects.
* Include paths and misc items like linker scripts may need to be fixed after import.
