# DS18B20 Commands

9-12 bit Celsius temperature with alarm.

## ROM ID 

Byte 0: 0x28 (family code)

Bytes 1-6: 48 bit serial number

Byte 7: CRC8 of bytes 0-6

## Function Commmands

* Temperature Conversion (0x44): 12 bit conversion requires 750 us
* Read Scratch Pad (0xBE): read 9 bytes of data
